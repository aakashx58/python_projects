# Python Projects

A collection of beginner-friendly Python mini-projects:

- **Coffee Machine Simulator** — simulates a coffee machine that makes espresso, latte, and cappuccino, checks resources, and handles transactions.
- **Love Calculator** — calculates a "love score" between two names.
- **Rock Paper Scissors** — play rock-paper-scissors against the computer.

## Requirements

- Python 3.x

## How to run

Open a terminal in the folder of the project you want to run and execute its main file:

```bash
# Coffee Machine Simulator
cd coffee_machine
python main.py

# Love Calculator
cd love_calculator
python Lovecalculator.py

# Rock Paper Scissors
cd rock_paper_scissor
python rock_paper_scissor.py
```
